# Склад для магазина

Консольная программа учёта товаров для небольшого магазина, написанная на Python 3. Помогает принимать поставки, списывать продажи, смотреть остатки и рассчитывать общую стоимость склада.

Данные сохраняются в JSON-файле и остаются доступными после закрытия программы. Интернет и дополнительные библиотеки не нужны.

## Возможности

- Добавление товара с количеством и ценой.
- Увеличение остатка и обновление цены, если товар уже есть.
- Списание товара без возможности уйти в отрицательный остаток.
- Автоматическое удаление товара из списка, когда остаток равен нулю.
- Отчёт об остатках в алфавитном порядке.
- Подсчёт общей стоимости склада.
- Сохранение и загрузка данных из JSON.
- Интерактивное меню для работы без повторного ввода команд.

Названия товаров не зависят от регистра и пробелов по краям: `"Мыло"`, `"МЫЛО"` и `" мыло "` считаются одним товаром.

## Требования

- Python 3.
- Только стандартная библиотека Python (`argparse`, `json`, `sys`).

## Запуск

Откройте терминал в папке с файлом `warehouse.py`. На macOS команды можно запускать так:

```bash
python3 warehouse.py add "Мыло" 20 350.5
```

По умолчанию данные хранятся в `store.json` в текущей рабочей папке. Если файла ещё нет, программа начинает с пустого склада и создаёт файл при первой успешной записи.

## Команды

### Добавить поставку

```bash
python3 warehouse.py add "Порошок Tide" 10 2500
```

Результат:

```text
Добавлено: порошок tide — 10 шт. по 2500.00
```

Если товар уже существует, новое количество прибавится к текущему, а цена заменится новой.

### Списать товар

```bash
python3 warehouse.py remove "порошок tide" 3
```

Результат:

```text
Списано: порошок tide — 3 шт. Осталось: 7
```

Нельзя списать больше товара, чем имеется на складе.

### Посмотреть остатки

```bash
python3 warehouse.py list
```

Пример результата, если предварительно добавить 20 штук мыла по 350.50 и 10 штук порошка по 2500.00, затем списать 3 штуки порошка:

```text
мыло: 20 шт. x 350.50 = 7010.00
порошок tide: 7 шт. x 2500.00 = 17500.00
```

### Общая стоимость склада

```bash
python3 warehouse.py total
```

Для склада из примера выше:

```text
Стоимость склада: 24510.00
```

### Интерактивное меню

```bash
python3 warehouse.py menu
```

В меню можно выбрать действие по номеру:

1. Добавить товар.
2. Списать товар.
3. Посмотреть остатки.
4. Общая стоимость склада.
5. Выход.

### Другой файл склада

Чтобы хранить данные отдельно, передайте `--file` **перед командой**:

```bash
python3 warehouse.py --file test_store.json add "Шампунь" 5 1200
python3 warehouse.py --file test_store.json list
```

## Обработка ошибок

Программа проверяет корректность названия, количества и цены, существование товара и достаточность остатка. Сообщения об ошибках для обычных команд начинаются с `Ошибка:`, выводятся в `stderr` и сопровождаются кодом завершения `1`. Успешные команды завершаются с кодом `0`.

Например:

```bash
python3 warehouse.py remove "мыло" 100
```

Если на складе только 20 штук:

```text
Ошибка: на складе только 20 шт. товара «мыло»
```

Если JSON-файл повреждён, программа сообщает об ошибке вместо потери сохранённых данных.

## Формат данных

Файл хранится в кодировке UTF-8. Пример `store.json`:

```json
{
  "items": {
    "мыло": {
      "qty": 20,
      "price": 350.5
    }
  }
}
```

Вся программа находится в `warehouse.py`. Основные функции: `load`, `save`, `add_item`, `remove_item`, `total_value`, `report`. Функции логики работают с данными; ввод и вывод выполняются в командной части программы.
